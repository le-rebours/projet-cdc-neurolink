# 5.3 Environnement technique

| Module | Environnement |
|--------|----------------|
| **Axe 1** | Architecture réseau et cloisonnement |

| | Firewall : pfSense |

| | Serveur WEB : apache, ngnix, caddy ou frankenphp |

> [!WARNING]
> **Documentation technique** \
> L'équipe infrastructure rédige l'intégralité de sa documentation en Markdown, dans `/documentation` à la racine du **dépôt WEB** du groupe. Les règles d'organisation (INDEX, sous-répertoires, schémas) sont dans [conventions/documentation-technique.md](../../conventions/documentation-technique.md).
